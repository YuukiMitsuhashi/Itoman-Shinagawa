Workflow

  1. 1. Load a video (left)
  2. 2. Click the swimmer to track
  3. 3. Calibrate real-world distance
  4. 4. Mark wall / lane length
  5. 5. Run analysis

2. Select swimmer

Scrub to a frame where the swimmer is visible. Detect people, then click the swimmer. The selected body becomes the tracking target for the entire video.

3. Calibrate real-world distance

Click two points whose real distance is known. Best choices: two visible lane-rope markers or two points along the swimmer's travel line.

4. Race setup + wall marking

0 / 2 walls
For a 25 m pool, mark the visible wall/turn line at each end. This is separate from pixel-to-meter calibration and makes length/turn detection much more stable.

5. Run analysis

Analysis seeks through the whole video and runs pose estimation. Lower sample intervals increase detail but can make processing much slower.

What it calculates

• Whole-video distance, elapsed race time, average/max speed
• Every detected 25/50 m length and split
• Turn/length detection using the marked wall positions
• Stroke per length, including IM's Fly → Back → Breast → Free sequence
• Approximate stroke rate from wrist motion
• Approximate kick activity from ankle motion
• Speed-vs-time graph and CSV/JSON export
